## Running the notebook

The analysis is contained in the file `FINAL-060926-SUBMIT.ipynb`.

The original arXiv snapshot (`arxiv-metadata-oai-snapshot.json`, several GB) is not included. It can be downloaded from the Kaggle dataset, the link to which is provided below.

The resulting labelled dataset, `arxiv_cs_labelled.csv`, is included in the archive, and the notebook can be run without the original snapshot.

The file manual_validation_sample.csv contains the pre-labelled manual labels used to calculate agreement and the kappa coefficient.
